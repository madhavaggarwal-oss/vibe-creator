## Platform Requirements

**Development:**
- Node.js LTS (compatible with Next.js 16)
- npm (for package management)
- macOS/Linux/Windows (cross-platform compatible)
- 2GB+ free disk space (node_modules)

**Production:**
- Deployment: Vercel (primary target, evidenced by `.vercel/` directory and `@vercel/blob` integration)
